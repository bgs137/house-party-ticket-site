# House Party Ticket Site

Welcome to the House Party Ticket Site! This project is designed to provide a seamless experience for users to browse and purchase tickets for various house parties.

## Features

- **Home Page**: A landing page that introduces users to the site and showcases upcoming events.
- **Event Details**: Detailed information about each event, including date, time, location, and ticket purchasing options.
- **Checkout Process**: A user-friendly checkout process for purchasing tickets, including form inputs for user information and payment details.
- **Responsive Design**: The site is designed to be responsive and accessible on various devices.

## Getting Started

To get started with the House Party Ticket Site, follow these steps:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/house-party-ticket-site.git
   cd house-party-ticket-site
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Run the Development Server**:
   ```bash
   npm run dev
   ```

4. **Open in Browser**:
   Navigate to `http://localhost:3000` in your web browser to view the application.
